# 🎓 Итоговая проектная работа: Бэкенд для приложения-блога на Spring Boot

**Студент (ФИО):** Стальмаков Даниил

## 👨‍💻 Описание
В данном проекте бэкенд приложения-блога был мигрирован со Spring MVC + сырой JDBC (сборка WAR, деплой на внешний Tomcat) на **Spring Boot 3.2+** с использованием встроенного сервлет-контейнера. 
Все старые API (получение постов, создание, лайки, комментарии) сохранены и продолжают работать. Также тесты слоя сервисов и DAO переписаны под использование `SpringBootTest`.

---

## 🚀 Как работать с бэкендом

### 1. Как собрать бэкенд
Для сборки приложения используется Maven. Приложение собирается в Executable Jar.
Выполните команду в корневой папке проекта:
```bash
mvn clean package -DskipTests
```

### 2. Как запустить тесты
Проект покрыт unit- и интеграционными тестами с использованием `@SpringBootTest` и кеширования контекста. 
Для запуска встроенных тестов выполните:
```bash
mvn clean test
```

### 3. Как запустить бэкенд
Приложение можно запустить из собранного jar-файла (после того как выполнена сборка):
```bash
java -jar target/my-blog-back-app.jar
```
Либо напрямую через плагин Spring Boot:
```bash
mvn spring-boot:run
```
По умолчанию бэкенд поднимается на порту `8080`. Консоль H2 доступна по адресу `http://localhost:8080/h2-console`.

### 4. Как использовать бэкенд
Вы можете отправлять REST-запросы к API (например, через Postman/cURL) по адресу `http://localhost:8080/api/posts`.

**Пример (Получение списка постов):**
```bash
curl "http://localhost:8080/api/posts?search=&pageNumber=1&pageSize=10"
```

**Пример (Добавление лайка):**
```bash
curl -X POST http://localhost:8080/api/posts/1/likes
```
