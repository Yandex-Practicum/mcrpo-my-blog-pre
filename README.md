1. Убедитесь в наличии необходимых инструментов
Перед началом работы убедитесь, что у вас установлены следующие инструменты:

Java Development Kit (JDK): Установите JDK 17 или более позднюю версию. Вы можете проверить установленную версию, выполнив команду:
bash java -version

Apache Maven: Установите Maven для управления зависимостями и сборки проекта. Проверьте установленную версию:
bash mvn -v

2. Клонирование репозитория
Клонируйте ваш проект из репозитория (если он находится на GitHub или другом удаленном репозитории):
bash git clone <URL_репозитория> cd my-blog-back-app

3. Обновление зависимостей
Перед сборкой приложения выполните команду, чтобы скачать все необходимые зависимости:
bash mvn clean install

Эта команда очистит проект (удалит папку target/) и соберет его заново, скачивая все зависимости, указанные в pom.xml.

4. Настройка конфигурации
Если ваше приложение использует конфиденциальные данные, такие как учетные данные базы данных, убедитесь, что файл application.properties (или application.yml) настроен правильно:

Пример конфигурации в application.properties:
properties spring.datasource.url=jdbc:h2:mem:testdb;DB_CLOSE_DELAY=-1;DB_CLOSE_ON_EXIT=FALSE spring.datasource.driver-class-name=org.h2.Driver spring.datasource.username=sa spring.datasource.password=password spring.h2.console.enabled=true spring.jpa.hibernate.ddl-auto=update

5. Сборка и запуск приложения
Чтобы собрать и запустить приложение, выполните следующую команду:

mvn spring-boot:run
6. Проверка работы приложения
После успешного выполнения команды вы должны увидеть вывод в терминале, который указывает, что приложение запущено. Обычно оно будет слушать на порту 8080 (по умолчанию).

7. Доступ к приложению
Вы можете открыть браузер и перейти по следующему адресу, чтобы получить доступ к вашему приложению:
http://localhost:8080/posts

Если вы активировали консоль H2, вы также можете получить доступ к ней по адресу:
http://localhost:8080/h2-console
При этом используйте следующие настройки для подключения:

JDBC URL: jdbc:h2:mem:testdb
Username: sa
Password: оставьте пустым.
8. Тестирование приложения
Если у вас есть тесты, вы можете запустить их с помощью команды:
bash mvn test

Заключение
Теперь вы знаете, как собрать и запустить ваше Spring Boot приложение. Если у вас возникнут вопросы или проблемы на любом этапе, не стесняйтесь спрашивать!
