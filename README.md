# My Blog Backend

Бэкенд приложения-блога на Spring Boot.

## Сборка проекта

```bash
mvn clean package
```

## Запуск тестов

```bash
mvn test
```

## Запуск приложения

```bash
java -jar target/my-blog-back-app.jar
```

Приложение запустится на `http://localhost:8080`. API доступен по пути `/api`.

## Запуск фронтенда

```bash
cd frontend
npm install
npm run dev
```

Фронтенд запустится на `http://localhost:3000`.
